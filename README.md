# BeeOnCode Internship — Admin Panel

React admin-panel work completed during my **BeeOnCode internship**, focused on Services management and REST API integration within an existing application.

## What I Worked On

- Service listing
- Create / edit / delete
- Publish / unpublish
- Service ordering
- Form validation
- Image / icon integration
- REST API integration
- Admin-panel UI workflows

## Stack

React · JavaScript · Fuse React · REST API · Git

## Services API

```http
GET    /auth/services/all
POST   /auth/services/add
GET    /auth/services/get/{id}
DELETE /auth/services/delete/{id}
PUT    /auth/services/edit/{id}
PUT    /auth/services/is_published/{id}
PUT    /auth/services/order
```
